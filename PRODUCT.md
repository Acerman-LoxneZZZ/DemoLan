# ПРОЯВЛЕНО

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated by the explicit user brief. Static semantic HTML, CSS, ES modules and small Node scripts for preview/build. No runtime dependencies.

## Users
Russian-speaking independent tutors, trainers, psychologists, doctors and consultants considering a professional landing page.

## Product Purpose
Make the value of a specialist visible and understandable before the first meeting; encourage a conversation about their future website.

## Capabilities and Constraints
Four clearly labeled interactive demonstration concepts, work scope, process, FAQ and short inquiry form. Real contacts, prices, achievements and backend have not been provided. The form must honestly prepare a copyable inquiry in demo mode. No public deployment without separate approval.

## Brand Commitments
Working name ПРОЯВЛЕНО. Metaphor: relief of expertise. The user rejected the initial muted treatment, then refined the colorful version toward black tones, substantial scroll-directed motion, an immediately visible 3D sculpture and stronger pointer response. The current approved implementation task uses black/graphite, glowing silver material, electric violet and acid-lime signals, Unbounded display type with Manrope body, and smooth card turns. The exclusive FAQ accordion remains. Russian language throughout. No human photography or invented professional credentials.

## Evidence on Hand
User's detailed approved brief, stored in the attachment. Demonstrations are authored concepts, not client work. No testimonials or sales claims.

## Accessibility & Inclusion
Keyboard operation, visible focus, responsive widths 360/390/768/1440, contrast, reduced motion, immediately readable content, ordinary cursor and natural scroll.

Current user selection: Ultraviolet is the default palette. Manrope replaces Unbounded on the main surface; FAQ opening and sign rotation are deliberately slower.
