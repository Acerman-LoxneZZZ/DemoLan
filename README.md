# ПРОЯВЛЕНО

Авторский лендинг о создании сайтов для частных специалистов. Текущая версия: чёрная сцена, основная гамма «Ультрафиолет» с лавандовыми акцентами и фиолетовым светом, Manrope в заголовках и тексте. Светящаяся WebGL-скульптура плавно доворачивается, концепты поворачиваются при прокрутке, наведении и выборе вкладки. FAQ и форма в деморежиме сохранены.

Первый экран теперь следует высоте окна: размер заголовка ограничен и шириной, и высотой; модель вписана в доступную высоту. Контейнер использует всю ширину с адаптивными полями. На телефоне остаётся обычный поток; при увеличении текста или очень низком окне страница может вырасти, не обрезая содержание. Визуальная проверка текущей версии пока ожидает снятия сохранённого запрета браузера на localhost. Проверки исходников и 58 тестов проходят; подробности — `docs/QA.md`.

## Запуск

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```powershell
npm run dev
```

Откройте [http://localhost:4173](http://localhost:4173). Остановить сервер — `Ctrl+C`. После изменения `src/config.js`, `src/page.js` или `src/concepts.js` перезапустите сервер; для CSS и браузерного JavaScript достаточно обновить страницу.

```powershell
npm run check
npm run build
```

`check` проверяет синтаксис и запускает 58 тестов заявки, аккордеона, прокрутки и геометрии. `build` создаёт готовую статическую папку `dist/` и обновляет корневой `index.html`. Для просмотра интерактивности используйте HTTP-сервер: открытие HTML двойным щелчком может блокировать ES-модули в браузере.

## Что где менять

**Все тексты, название, предложения, примеры и публичные подключения — в `src/config.js`.**

| Данные | Раздел конфигурации |
| --- | --- |
| Название и метаданные | `brand`, `title`, `description`, `canonicalUrl` |
| Email и ссылка на Telegram | `contacts.email`, `contacts.telegram` (полный адрес вида `https://t.me/имя`) |
| Главный экран | `hero` |
| Четыре концепта | `concepts.items` — сохраняйте технические `id` |
| Состав работы и этапы | `scope`, `process` |
| Вопросы и ответы | `faq` |
| Поля, уведомления и режим формы | `form` |
| Меню и подвал | `navigation`, `footer` |

Пустые контакты не показываются. После замены контента выполните `npm run build`. Длинные названия и существенно более объёмные тексты стоит ещё раз посмотреть на телефоне.

Актуальные цвета, типографика и контурное свечение — в `src/identity.css`, который подключается последним. `src/experience.css` сохраняет геометрию сцены и базу эффектов; его прежняя палитра перекрыта текущими токенами. Базовая сетка и адаптация остаются в `src/styles.css`. Повороты карточек находятся в `src/card-motion.js`/`src/card-motion.css`; отдельные слои отвечают за scroll, pointer и переключение. Самостоятельные мини-сайты описаны в `src/concepts.js` и `src/concepts.css`. Семантическую страницу собирает `src/page.js`; браузерные сценарии находятся в `src/main.js`, аккордеон — в `src/motion.js`, единая режиссура прокрутки — в `src/scroll-scenes.js`, WebGL-сцена — в `src/sculpture.js`, чистая геометрия — в `src/ribbon-geometry.js`, валидация — в `src/inquiry.js`.

## Форма

По умолчанию `form.mode: 'demo'`. Данные остаются в открытой вкладке; хранилище, аналитика и отправка не используются. После проверки полей появляется подготовленный текст заявки с кнопкой копирования. Если браузер не даёт доступ к буферу обмена, текст выделяется для ручного копирования. Перезагрузка очищает данные.

Чтобы подключить свой обработчик:

1. Подготовьте серверный HTTPS endpoint. Он должен принимать `POST` с `Content-Type: application/json` и полями `name`, `specialization`, `contact`, `message`.
2. Включите CORS для своего домена, если обработчик размещён на другом домене. На сервере добавьте собственную проверку полей, ограничение частоты запросов и защиту от спама.
3. Отвечайте HTTP `2xx` **только после реального приёма заявки**. Иной статус или таймаут покажет ошибку и предложит копирование; максимальное ожидание — 15 секунд.
4. Укажите URL в `form.endpoint`, затем `form.mode: 'endpoint'`. Обновите тексты `connectedNotice` и `connectedPrivacy` под свой реальный порядок обработки данных. Секретные ключи должны оставаться на сервере.
5. Проверьте отправку на своём сервисе и только затем публикуйте.

Сам сервер отправки, доставка в email/Telegram, CRM, CMS, аналитика и домен не подключены. В деморежиме страница честно предупреждает об этом.

## Графика и шрифты

Главная скульптура — собственная гладкая жёсткая WebGL-геометрия со скруглёнными фасками, плотным разбиением широких граней, непрерывной траекторией и согласованными нормалями. Прежняя деформация вершин удалена. Ракурсы ограничены, чтобы фигура не исчезала ребром. Внешняя 3D-библиотека не требуется. При недоступном WebGL остаётся статичная графика: авторская тень, созданная встроенным ImageGen. Исходник — `assets/shadow-source.png`, итоговый промпт — `assets/image-prompt.md`. Подготовлены WebP-варианты 720 px (~57 КБ) и 1440 px (~212 КБ). Исходное изображение имеет 1254×1254 px; вариант 1440 увеличен для единообразного `srcset`. Исходный PNG не попадает в `dist/`.

Unbounded (заголовки), Manrope (текст) и Cormorant Garamond (только концепт психолога) размещены локально, с кириллицей и `font-display: swap`; лицензии SIL OFL находятся в `assets/fonts/`. Внешних запросов к сервису шрифтов нет. Источники Unbounded и проверка кириллицы — `docs/type-assessment-v4.md`, лицензия — `assets/fonts/unbounded-OFL.txt`. Источники: [Manrope](https://fonts.google.com/specimen/Manrope), [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond).

## Доступность и движение

Текст и кнопки видимы сразу. Обычный курсор, естественная прокрутка, заметный фокус, вкладки с клавишами ←/→/Home/End. FAQ использует нативные `details`, одновременно открыт только один ответ; плюс превращается в минус, высота меняется плавно.

Один контроллер прокрутки направляет поворот скульптуры, раскрытие галереи в перспективе, последовательное появление смысловых строк, складывание объёмных панелей, непрерывную сборку страницы и финальную типографику. На мобильном диаграмма процесса закрепляется над этапами. Прокрутка назад восстанавливает сцены, колесо и жесты не перехватываются.

На устройствах с сенсорным указателем WebGL-сцена получает трёхсекундное вступление и останавливается; последующая прокрутка запускает плавное доворачивание с остановкой после достижения позы. Критическое демпфирование сохраняет скорость при изменении цели; реакция не зависит от частоты кадров. Указатель управляет ракурсом на всей области первого экрана. Движение учитывает `prefers-reduced-motion`; в подвале есть дополнительная кнопка «Меньше движения». WebGL останавливается вне экрана и в скрытой вкладке. Рендер использует до 60 кадров в секунду при повороте и до 45 в покое; на слабых и сенсорных устройствах — до 30; плотность canvas не выше 1.5, на слабых устройствах — 1.25.

## Перед публикацией

- Подтвердите рабочее название, свои формулировки и объём услуг.
- Укажите реальные контакты и адрес сайта `canonicalUrl`.
- Выберите и подключите обработчик заявок; подготовьте необходимые для вашего процесса тексты об обработке данных.
- Замените демонстрационные концепты реальными работами, когда они появятся, или сохраните явные подписи «концепт».
- Проверьте отправку на своём домене и размещение статической папки `dist/`.

Страница не содержит вымышленных клиентов, отзывов, достижений, цен, сроков или гарантий обращений. Публичная публикация в рамках этой работы не выполнялась.

Результаты проверки — `docs/QA.md`. Дизайн-система — `DESIGN.md`.

Текущая сборка `dist/` — около 694 КБ. Свечение модели создаётся собственным emissive rim shader и contour drop-shadow, без внешней 3D-библиотеки. Переход карточек отменяемый: исходящая копия продолжает текущую позу при быстрых кликах, она inert и скрыта от accessibility.

## Варианты цветов

[Открыть примерку](http://localhost:4173/?palette=1#top), затем нажать «Цветовые варианты» справа внизу. «Ультрафиолет» — выбранная основная гамма; остальные варианты — «Арктика» (голубой/кобальт), «Коралл» (персик/розовый), «Шампань» (золото/песочный), «Ультрафиолет» (лаванда/фиолетовый). Меняются акценты интерфейса, контурное свечение и освещение WebGL. Выбор временный, без storage и cookie; обычный URL не содержит панели и сохраняет текущую гамму.

Палитры — `src/palette-tokens.css`, панель примерки — `src/palette-preview.js`/`.css`, подстройка окна — `src/viewport.css`. Последний каскад: identity → palette-tokens → viewport → palette-preview. `min-height` позволяет первому экрану расти при zoom, а не прятать элементы за фиксированной высотой. Внешний вид V5 ещё не подтверждён в browser из-за сохранённого origin deny.

Текущая настройка — `site.palette: ultraviolet` в `src/config.js`, палитра присутствует в HTML до запуска JavaScript. Preview начинает с активной гаммы. FAQ раскрывается за850мс и закрывается за520мс; знак меняется за800–850мс, reduced motion сохранён. Основной интерфейс использует Manrope; Unbounded больше не подключается страницей.

Три дополнительных scroll-сцены: свет и подчёркивание по строкам смыслового заголовка; пункты состава работы разворачиваются как листы; вопросы приходят попеременно слева/справа с прорисовкой разделителей. Все управляются существующим `scroll-scenes.js`, внешний вид — `scroll-details.css`. Контент остаётся видимым, чтение не требует анимации.

## Демонстрационная витрина внизу

Открыть: [до / после и настроения](http://localhost:4173/#demo-playground). До правок исходная версия была отправлена в `origin/main`, коммит `1a0cee25afd6674e2a77c55b16a2582d29af8dfe`. Эксперимент находится в отдельной ветке `codex/demo-playground`.

Витрина расположена после формы. Можно перетаскивать границу прямо по изображению либо пользоваться видимым нативным ползунком под ним; стрелки и Home/End работают с клавиатуры. «Выразительно» использует Unbounded и ультрафиолет, «Точно» — Manrope и голубой, «Тепло» — Cormorant Garamond и шампань. Цвета, шрифт и свет меняются только в витрине. Кнопка восстановления возвращает её начальные настройки.

Новая WebGL-модель — три связанных тороидальных кольца. Поддерживает перетаскивание, сглаживание, локальные цвета и остановку после вступления/доворачивания. При отсутствии WebGL остаётся SVG; reduced motion показывает статичную сцену с обновлением цветов. Реальная GPU-отрисовка этой версии браузером пока не проверена.

Отключить эксперимент: `playground.enabled: false` в `src/config.js`, затем сборка и перезапуск сервера. Полный исходный вариант остаётся в `main`; при чистой рабочей директории можно переключиться на неё и перезапустить сервер. Пользовательская реакция верхней S-модели теперь ограничена её областью, амплитуда увеличена, инерция сохранена.

Тексты/демо-состояния витрины — `src/playground.js`, её оформление — `src/playground.css`; новый renderer — `src/orbit-scene.js`, геометрия — `src/orbit-geometry.js`. Основной лендинг выше сохранён; единственная последующая правка сверху — явно запрошенная реакция S-модели на курсор.
