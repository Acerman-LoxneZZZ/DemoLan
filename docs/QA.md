## Рабочие сценарии

- Четыре вкладки меняют композицию и доступное имя панели; Home/End переключают крайние вкладки. Все ссылки концептов ведут к реальной форме обсуждения сайта.
- Мобильное меню открывается, закрывается по Escape и при выборе ссылки. Фокус после Escape возвращается на кнопку.
- FAQ открывается и закрывается клавишей Enter; видимый фокус подтверждён.
- Пустая форма показывает три ошибки, общее уведомление и фокусирует имя. После ввода имя/специализация/контакт очищаются от лишних пробелов.
- Заполненная заявка с тестовыми данными готовится без отправки; кнопка копирования показала «Текст скопирован». Отдельно реализован ручной fallback при недоступном Clipboard API; принудительное отключение API в браузере не эмулировалось.
- В тексте результата явно сказано, что автоматическая отправка не выполнена. Исправлен конфликт id секции контактов и поля контакта: все id уникальны, подписи связаны с полями.
- Все внутренние якорные ссылки имеют существующую цель.
- Указатель действительно меняет свет: после двух положений прочитаны значения смещения 1.82/0.31 px и 7.37/2.72 px; типографика сохраняет положение.
- Прокрутка процесса меняет состояние диаграммы от «Смысл» до «Страница». Все этапы остаются обычным доступным текстом.
- Кнопка «Меньше движения» переводит сцену в полную статичную страницу: `data-reduced-motion`, `transition-duration: 0s`, `scroll-behavior: auto`, стадия процесса 3.
